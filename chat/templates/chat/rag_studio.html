👋 Welcome to RAG Studio!

This module demonstrates Retrieval-Augmented Generation (RAG) from basic principles: 1. Document Ingestion & Chunking: Documents are split into semantic overlapping text chunks. 2. Vector Similarity Search: User queries are matched against chunk embeddings using Cosine Similarity to retrieve the Top-K relevant passages. 3. Context Prompt Injection: The LLM is provided with the retrieved passages to answer accurately with bracketed citations [1], [2] without hallucination.
